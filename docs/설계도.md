## 계산 규칙
- 잔액 = 시작잔액 + 입금 − 출금 ± 이체
- 신용카드 = 부채 계정(시작잔액 = −미결제액). 사용 시 지출 집계 + 카드 잔액 감소, 통장 잔액 불변
- 카드대금 납부 = 통장 → 카드 이체(지출에 다시 넣지 않음)
- 체크카드 = 연결 통장 출금
- 금액은 원 단위 정수, 반올림 없음

## 하지 말 것
- 엑셀에 TODAY 함수 사용 금지(출력일 값 기입)
- 카드대금을 지출 항목으로 기록 금지(이중 집계)
- 화면 가로 넘침 금지(320px 폭 확인)
